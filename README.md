# AI-инженер — мастер-класс Макса Люшера

HTML-презентация: 124 слайда, изображения, анимация и видео.

Открывайте опубликованный сайт GitHub Pages. Вход в аккаунт не нужен.

- Стрелки ← → переключают слайды.
- «Содержание» открывает список и поиск.
- «Страницей» включает непрерывную ленту.
- «Пауза» останавливает декоративную анимацию.
- Видео Глеба запускается кнопкой воспроизведения; звук доступен в плеере.

`index.html` использует относительные ссылки на файлы в `assets/`. Медиа и шрифты хранятся в этом репозитории. `manifest.json` содержит контрольные суммы файлов.
